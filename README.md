# Kronwerke screenshot world

The scenes of the test world `kronwerke:testworld`, where the pictures of the quest book are taken. Generated by `tools/shots/build.py` on the `main` branch; do not edit by hand.

On the server: `/kw testworld pull` fetches this branch into `kronwerke/shots/world`, `/kw testworld apply` builds it, `/kw cam run` takes the pictures.
