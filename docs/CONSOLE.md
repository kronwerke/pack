# Server console

What the dedicated server logs as WARN or ERROR, why, and what the pack does about it. Checked on 2026-09-30 with pack 0.5.5 (NeoForge 21.1.252) on the test server: a fresh start, the first minutes after "Done", and a `/reload`.

No log filters are used and no logger level was lowered. Every fix below removes the cause.

## Result

| Phase | Before | After |
| --- | --- | --- |
| Start until "Done" | 721 errors, 283 warnings | 5 errors, 240 warnings |
| First minutes after "Done" | 6 errors, 7 warnings | 0 errors, 6 warnings |
| Each `/reload` | 372 errors, 45 warnings | 2 errors, 8 warnings |

347 of the 721 start errors and all 6 errors after "Done" came from the test world itself (blocks and items of the removed Create: New Age, see "One time or test server only"). Without them the start had 374 errors.

Of the 240 warnings left at start, 199 come from Mixin (174 of them are the harmless "Reference map" and "Discarding @Unique" lines). See "Remaining".

## How the fixes ship

- Data fixes are datapack overrides in `kubejs/data/<namespace>/...`. KubeJS loads that folder on top of all mod data, so a file there replaces the file of the same path inside a mod jar.
- Two configs in `config/`.
- The CI job runs `packwiz refresh` on push, which adds the new files to `index.toml`.
- Most overrides are copies of a mod file with a small change. When one of these mods updates, compare the override with the new mod file and delete the override if the mod fixed it: Malum, Productive Bees, Mystical Agradditions, Farmer's Delight, Silent Gear, Iron Furnaces, Hexerei, When Dungeons Arise, Dungeons and Taverns, Industrial Foregoing, Eidolon Repraised, Terralith, Create: Steam 'n' Rails, Mekanism More Machine, Create Connected.

## Remaining

These cannot be fixed from the pack side. None of the mods has a newer 1.21.1 NeoForge release on Modrinth that fixes them (checked 2026-09-30); they need a fix in the mod.

| Message | Why it stays |
| --- | --- |
| `mixin: Reference map '<mod>.refmap.json' for <mod>.mixins.json could not be read` (90) | 90 mixin configs (74 different refmap names) name a refmap that is not in the jar. On NeoForge 1.21 the game runs with Mojang names, so no refmap is needed. Harmless. Only the mod authors can remove the entry. |
| `mixin: Discarding @Unique public method ... in copycats-...mixins.json` (84) | Copycats+ adds methods to its own block classes that already have them. Harmless, Copycats+ 3.0.9 is the latest. |
| `mixin: Error loading class: ...` and `@Mixin target ... was not found` (21 lines) | Optional compat mixins for mods that are not installed or have moved classes: Sable and Create Simulated (Power Grid, Create Diesel Generators, Create Crafts and Additions, Create Connected), Quark (Apotheosis, Apothic Enchanting), Lithium's old package (Copycats+), old Refined Storage (ModernFix), Aliens vs Predator (NeoOrigins), an old Simple Voice Chat class (Steam 'n' Rails), a JetBrains annotation (Create). These lines come from the mixin config plugins of those mods, which try to load the target class to decide whether to apply; no pack config can skip that check. The mixins are simply not applied. Turning off ModernFix `mixin.bugfix.unsafe_modded_shape_caches` would remove the Refined Storage line but add a ModernFix "Option overriden" warning instead, so it stays on. |
| `RuntimeDistCleaner: Attempted to load class net/minecraft/client/gui/components/Button$OnPress for invalid dist DEDICATED_SERVER` (ERROR) and the matching mixin line | Cable Tiers has a client-only mixin (`InvokerActionButton`) in its common mixin list. ## Mod updates

- None of the remaining messages is fixed by a newer release yet. Worth reporting upstream: Create Enchantment Industry (XP fluid ids), Create Dragons Plus (data maps without Sable), Cable Tiers (client mixin), Eidolon Repraised (affix id), Power Grid (missing native), NeoOrigins (built-in legacy powers), Steam 'n' Rails (loot table conditions, voice chat compat), Mekanism More Machine and Create Connected (unguarded loot tables), Productive Bees (Botania recipes), Malum (compat recipes).
- Terralith 2.6.2 (1.21.1, NeoForge, needs Lithostitched, which we have) rewrites these biomes; `alpha_islands` no longer has axolotls. It is a large world generation update, so only take it before the season world is generated. If taken, delete `kubejs/data/terralith/`.
